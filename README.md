# Asansör Kapı Butonu Dışişleri

Bu depo bir şakadır. Aynı zamanda bir bakanlıktır. İkisi aynı anda doğrudur; asansör bunu kabul etmez.

## Misyon

Dünyanın en inatçı diplomatik aktörü olan **kapat butonu** ile müzakere yürütmek. Buton basılır. Kapı kapanmaz. Nota çekilir. Kat değişir. Kimse inmez. Tarih yazılır.

Bu yazılım:

- gerçekten çalışır
- hiçbir asansörü tamir etmez
- kapıyı kapatmaz, sadece kapatıyormuş gibi tutanak tutar
- kat pazarlığını uluslararası kriz formatında raporlar

## Kurulum

```bash
git clone https://github.com/Tentivory/asansor-kapi-butonu-disisleri
cd asansor-kapi-butonu-disisleri
python3 diplomat.py
```

Bağımlılık yoktur. Python 3 yeter. İnternet gerekmez. Yerçekimi opsiyoneldir, genelde gelmez.

## Kullanım

```bash
python3 diplomat.py --kat 7 --yolcu 4 --buton kapat
python3 diplomat.py --kat 0 --yolcu 1 --buton ac --acele
python3 diplomat.py --tutanak
```

`--tutanak` gizli arşivi açar. Arşiv sıkıcıdır. Sıkıcılık kasıtlıdır.

## Protokol

1. Butona basılır.
2. Buton bunu bir nota addeder.
3. Kapı, notayı okumuş gibi yapar.
4. Orta kat veto hakkını kullanır.
5. Rapor üretilir. Rapor asansörü hareket ettirmez.

## Yasal uyarı

Bu bakanlık gerçek bir bakanlık değildir. Gerçek asansör butonlarına bağlı değildir. Gerçek dışişleri mensuplarını temsil etmez. Kapı yine de kapanmayabilir; bu yazılımın suçu değil, kapının kişilik hakkıdır.
